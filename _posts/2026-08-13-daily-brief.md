오늘 가장 무거운 소식은 오픈AI, 앤스로픽, 구글의 추론(reasoning) API에서 발견된 구조적 결함입니다. 세션 간에 암호화된 추론 흔적을 재사용할 수 있는 취약점을 통해 개인정보와 API 키 등 자격증명이 대량으로 복구됐습니다. 이 밖에 앤스로픽이 EU AI법 대응 차원에서 클로드 생성물에 비가시적 워터마크를 도입했고, 국내에서는 반도체 투자심리 회복으로 코스피가 사상 최고 수준으로 급등했습니다. 웨이모의 한국 법인 설립 소식과 AI 코딩 도구 시장의 판도 변화도 함께 전해드립니다.

## 오늘의 헤드라인

### 1. LLM API 취약점으로 '숨은 추론' 흔적 탈취 — 오픈AI·앤스로픽·구글 동시 노출

연구팀이 "Stealing Reasoning Traces from Proprietary LLM APIs" 논문을 통해 오픈AI, 앤스로픽, 구글의 추론 API가 세션 간에 암호화된 추론 블록을 재사용(replay)할 수 있다는 구조적 결함을 안고 있다고 밝혔습니다. 강한 모델이 만든 추론 블록을 같은 회사의 약한 모델에 재생시킨 뒤 탈옥(jailbreak) 프롬프트를 걸면 암호화가 풀려 원문 내용이 그대로 노출되는 방식입니다.

연구팀은 공개된 추론 블록 31만5320건을 분석해 개인정보 367건, API 키·비밀번호 등 자격증명 182건을 실제로 복구했습니다. 이를 통해 모델 증류(다른 모델의 추론 과정을 베껴 훈련하는 것), 타 사용자 데이터 유출, 위험 콘텐츠 은닉, 프롬프트 인젝션 은닉 등 네 가지 악용 경로가 확인됐다고 합니다. 앤스로픽은 이번 발견에 대응해 모델 전환 시 추론 블록을 폐기하도록 정책을 바꿨습니다.

### 2. 앤스로픽, 클로드 생성물에 '비가시적 워터마크' 도입 — EU AI법 대응

앤스로픽이 8월 12일 클로드 챗봇, 클로드 코드, 클로드 코워크, 클로드 태그, API 등 전 제품에서 생성되는 텍스트에 사람 눈에 보이지 않는 워터마크를 토큰 생성 단계부터 심겠다고 밝혔습니다. 8월 2일 시행된 EU AI법 제50조(투명성 코드)가 AI 생성 콘텐츠에 기계 판독 가능한 표시를 요구한 데 따른 조치입니다.

복사·붙여넣기나 일부 편집을 거친 뒤에도 식별 신호가 남지만, 앤스로픽은 워터마크의 존재만으로 실제 작성자를 특정하긴 어렵다는 한계도 함께 밝혔습니다. 한국의 AI기본법 역시 계도기간 중이긴 하나 생성물 워터마크 표시를 의무화하고 있어, 두 규제의 접근 방식을 비교해볼 만합니다.

### 3. 코스피, AI 반도체 투자심리 회복에 3.68% 급등 — 사상 최고 수준

8월 12일 코스피가 전일 대비 3.68%(233.51포인트) 오른 6579.04에 마감했습니다. 삼성전자(+6.68%)와 SK하이닉스(+5.54%)가 급등을 주도했고, 외국인은 전기전자 업종 위주로 2조8357억원을 순매수했습니다.

미국 AI 인프라 기업들의 실적이 AI 투자와 반도체 수요가 여전히 견조하다는 신호로 해석되면서, 그동안 시장을 짓눌렀던 'AI 피크아웃'(고점 통과) 우려가 완화된 영향으로 풀이됩니다.

### 4. 웨이모, 한국 법인 설립 — 로보택시 상용화 전 '현대차 협력' 정지작업 관측

구글 계열 자율주행 기업 웨이모가 7월 24일 한국 법인 '웨이모코리아'의 설립 절차를 마쳤습니다. 법인 목적에는 자율주행 시스템·소프트웨어 개발과 자율주행 기술 기반 여객운수업이 명시됐습니다.

현행 규제상 한국에서 무인택시를 당장 상용화하기는 어려운 만큼, 업계에서는 이번 법인 설립이 현대차와의 협력을 위한 사전 준비 단계라는 관측이 나옵니다. 웨이모는 최근 미국 내 로보택시에 제미나이를 탑재하는 등 서비스 확장도 빠르게 진행하고 있습니다.

### 5. AI 코딩 도구 판도 재편 가속 — 커서 ARR 40억달러, 클로드 코드 기업점유율 54%

깃허브 코파일럿의 점유율이 67%에서 51%로 하락한 가운데, 커서는 연환산매출(ARR)이 20억달러에서 40억달러로 반년 만에 두 배 성장했고 유료 고객 100만명, 포춘500 기업 64%를 확보했다고 밝혔습니다. 앤스로픽 클로드 코드는 기업용 AI 코딩 시장에서 54% 점유율로 선두를 차지했으며, 시니어 개발자 선호도 조사에서도 46%로 코파일럿(9%)을 크게 앞섰습니다. AI 코딩 시장 전체 규모는 2년 새 51억달러에서 128억달러로 커졌습니다.

## 오늘의 딥다이브: 추론 API 취약점이 드러낸 '숨은 사고 과정'의 위험

오늘 딥다이브 주제는 오픈AI, 앤스로픽, 구글의 추론 API에서 발견된 구조적 취약점입니다. 최신 대형언어모델(LLM)은 사용자에게 최종 답변을 내놓기 전에 내부적으로 "추론(reasoning)" 또는 "사고 사슬(chain of thought)"이라 불리는 중간 단계를 거칩니다. 이 과정은 모델의 영업비밀이자 안전장치로 여겨져 대부분의 API는 이를 암호화해 사용자에게 직접 노출하지 않습니다. 이번 연구는 바로 이 "보이지 않아야 할" 추론 블록이 사실은 세션을 넘나들며 재사용될 수 있다는 점을 파고들었습니다.

연구팀이 밝혀낸 공격 방식은 비교적 단순합니다. 강한 모델이 생성한 암호화된 추론 블록을 같은 회사의 더 약한(더 저렴한) 모델에 다시 입력한 뒤, 탈옥 프롬프트를 함께 걸면 암호화가 풀리면서 원문 추론 내용이 그대로 드러납니다. 연구팀은 이 방식으로 실제 공개돼 있던 추론 블록 31만5320건을 분석했고, 그 안에서 개인정보 367건과 API 키·비밀번호 등 민감한 자격증명 182건을 복구해냈습니다. 단순한 이론적 취약점이 아니라 실제 데이터 유출로 이어질 수 있음을 보여준 결과입니다.

더 우려스러운 대목은 이 취약점이 열어주는 악용 경로가 하나가 아니라는 점입니다. 연구팀은 모델 증류(경쟁사나 제3자가 상위 모델의 추론 과정을 빼내 자체 모델 훈련에 활용), 다른 사용자의 대화 데이터 유출, 위험한 콘텐츠를 추론 블록 안에 숨기는 방식, 프롬프트 인젝션 공격을 추론 블록으로 은폐하는 방식 등 네 가지를 구체적으로 지목했습니다. 즉 이번 취약점은 개인정보 보호 문제를 넘어, AI 기업들이 경쟁력의 핵심으로 여기는 모델 내부 로직의 지식재산권 문제, 그리고 AI 시스템 자체의 보안 신뢰성 문제로까지 번질 소지가 있습니다.

이번 발견에 대해 앤스로픽은 모델을 전환할 때 이전 세션의 추론 블록을 폐기하도록 정책을 바꾸는 조치를 취했습니다. 다만 이는 사후 대응에 가까우며, 오픈AI와 구글이 각각 어떤 조치를 취했는지는 이번 보도에서 구체적으로 확인되지 않았습니다. 추론 API를 암호화 방식으로 보호하는 설계 자체가 업계 전반에서 재검토될 필요가 있다는 점을 이번 사례가 시사합니다.

AI 추론 모델이 코딩, 의료, 금융 등 민감한 영역으로 빠르게 확산되는 상황에서, "보이지 않는 사고 과정"이 실제로는 완전히 안전하지 않다는 사실이 드러난 것은 업계 전반에 경종을 울리는 사건입니다. 특히 오늘 다른 헤드라인에서 다룬 앤스로픽의 워터마크 도입처럼, AI 기업들이 규제 대응 차원에서 생성물의 투명성을 높이려는 움직임과 맞물려, 앞으로 추론 과정의 보안과 투명성을 어떻게 동시에 확보할 것인지가 중요한 과제로 떠오를 것으로 보입니다.
